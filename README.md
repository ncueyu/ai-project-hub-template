# 專案展示中心

把你做的網頁——教材、小測驗、班級公告、學生作品——放上網，
用**一個網址**分享出去。每個專案可以設成公開、需要密碼、或完全不公開。

這是一份**空白的**展示中心：裡面沒有任何專案，站名還沒設定，
也還沒連上你的帳號。底下三個指令就能開始。

> **你不需要會寫程式。** 整份說明可以直接貼給你的 AI 助理，讓它幫你執行。
> 這個資料夾裡的 `AGENTS.md` 就是寫給 AI 讀的操作規則，它會照著做。

## 你只要做這一件事

**把下面框框裡的話整個複製，貼給你的 AI 助理：**

> 請幫我建立我的專案展示中心。步驟是：
> 1. 執行 `node scripts/check-tools.mjs` 檢查我的電腦裝好了沒，缺什麼就告訴我怎麼裝。
> 2. 執行 `corepack pnpm install` 安裝這個專案需要的東西。
> 3. 執行 `node bin/hub.mjs init` 建立我的展示中心。
>
> 每一步做完先告訴我結果，需要我操作的地方請講清楚要按什麼。

指令長什麼樣、什麼時候要按「是」、出現看不懂的訊息怎麼辦，AI 都會告訴你。
**你不需要看懂那些指令。**

### 過程中會發生的兩件事

1. 安裝軟體時會跳出「**要允許這個應用程式變更你的裝置嗎**」，請按**是**。
   按「否」的話那一樣就不會裝上去。
2. 裝完之後**要把終端機關掉重開**，新裝的指令才會生效。
   沒重開的話你會看到「找不到指令」，那不是安裝失敗。

### 那三個指令各自在做什麼

不想全部交給 AI、想自己執行的話，可以照這個順序：

| 指令 | 做什麼 |
|---|---|
| `node scripts/check-tools.mjs` | 檢查五樣工具裝好了沒。**還沒安裝依賴也可以先跑**，缺什麼會直接印出安裝指令 |
| `corepack pnpm install` | 安裝這個專案需要的東西。`pnpm` 可能不在你的 PATH 裡，但 Node 內建的 `corepack` 可以直接用，所以前面要加它 |
| `node bin/hub.mjs init` | 建立**你自己的**展示中心：問你站名、設定後台密碼、建立資料庫、第一次上線 |

做完這三步，你就有一個自己的網址了。

## 不想申請帳號，只想先在自己電腦上看看

可以，而且不會動到網路上的任何東西：

```
corepack pnpm install
```
```
copy .dev.vars.example .dev.vars
```
```
corepack pnpm exec wrangler d1 migrations apply ai-project-hub-db --local
```
```
npm run dev
```

然後打開它印出的網址。管理後台在 `/admin/`，
本機用的密碼是 `admin-dev-only`（寫在 `.dev.vars.example` 裡，只給本機測試）。

本機版可以新增專案、改站名、換版面，把整個介面摸過一遍。

> 這條路徑不需要部署。至於「完全沒有 Cloudflare 帳號」的情況，
> 作者沒有在那樣的環境實測過，所以這裡不寫「完全不需要帳號」。

## 放一個專案上去

把你的網頁資料夾複製到 `要部署的專案/` 底下，然後告訴你的 AI：

> 幫我部署 `要部署的專案/我的測驗`

它會執行 `node bin/hub.mjs ship 要部署的專案/我的測驗`。

資料夾還不是「可以部署的樣子」也沒關係，跟 AI 說：

> 我做了一個網頁想放上去，幫我把 `要部署的專案/我的測驗` 變成可以部署的

它會幫你把網頁檔案搬進 `public/`、產生設定檔——動手前會先列清單問過你。

**部署成功之後，展示中心還是空的**——這不是壞掉。
新專案一律預設為**私人**（忘記設定的結果應該是沒人看得到，
而不是全世界都看得到）。到 `/admin/` 把它改成「公開」，重新整理就會出現。

`要部署的專案/README.md` 有更完整的說明，包含一件重要的事：
**那個資料夾裡的東西會被工具改動，請把你的原始程式留在別的地方。**

## 管理後台

網址是 `/admin/`，用你在 `hub init` 時設定的密碼登入。
上方有四個分頁：**專案**、**分類與標籤**、**推薦連結**、**站台設定**。

| 你想做的事 | 在哪個分頁 | 要不要重新部署 |
|---|---|---|
| 改站名、換版面、換配色、換圖示 | 站台設定（`/admin/#settings`） | 不用，存檔就生效 |
| 把專案改成公開／私人 | 專案 | 不用 |
| 指定某個專案當「主卡片」（會變大張、排第一） | 專案 | 不用 |
| 整理分類與標籤 | 分類與標籤 | 不用 |
| 貼上別人做的好工具網址 | 推薦連結 | 不用 |
| 給某個專案設密碼 | 專案 | **要**。密碼是部署當下注入的 |

最後一列是這套系統唯一一個「存好了還沒生效」的設定，所以特別列出來。
在重新部署之前，知道網址的人仍然打得開。

**網站配色有四種**：原始配色（預設）、科技藍、墨綠、青藍。
選了之後展示中心與後台會一起換。不改的話就是原始配色，跟你剛下載時一樣。

## 出事的時候

```
node bin/hub.mjs pitfalls
```

這裡列的坑有個共同特徵：**不會有錯誤訊息**——部署會顯示成功、
掃描會回報乾淨、程式會跑完，但結果是錯的。
所以「沒有報錯」不等於「沒有問題」。

更完整的排錯教學在作者的展示中心：https://ai-project-hub.yucs.workers.dev/stage-1/

## 會花錢嗎

用到的兩個服務（Cloudflare Workers 與 D1）都有免費額度：

| 項目 | 免費額度 | 超過會怎樣 |
|---|---|---|
| 網站被瀏覽 | 100,000 次／天 | 請求失敗回錯誤 |
| 資料讀取 | 500 萬列／天 | 查詢被擋 |
| 資料寫入 | 100,000 列／天 | 查詢被擋 |
| 儲存空間 | **5 GB 總量上限** | 要先刪資料才能再寫入 |

一個班級網站或教材頁，離這些數字都非常遠。
注意最後一列是**總量上限，不是每個月給你 5 GB**——影片請放 YouTube 再嵌入。

就這兩項服務而言，官方記載的超額行為一律是**功能被暫時擋下**，
而不是自動計費；沒有綁定付款方式時，官方文件中找不到任何自動扣款的機制。
這裡**不寫**「保證絕對不會收費」——官方文件裡沒有那句話。

## 已知的限制（不是待修的 bug）

- 管理後台的「上傳圖片」按鈕會回 503。縮圖有更輕量的做法：
  把截圖放在**專案資料夾根目錄**（不要放 `public/`），
  `hub ship` 部署時會自動裁切、轉檔、搬進來。
- `hub ship` 只處理純靜態專案，也不能用來部署展示中心自己
  （更新展示中心本身用 `npm run deploy`）。

## 這個資料夾裡有什麼

| 位置 | 是什麼 |
|---|---|
| `AGENTS.md` | 給 AI 助理讀的操作規則。**改規則只改這一份**，`CLAUDE.md` 與 `.agents/agents.md` 只是轉發 |
| `要部署的專案/` | 你要上線的專案放這裡 |
| `templates/範例專案-連連看/` | 一個現成的範例，可以直接拿來練習部署 |
| `public/` | 展示中心自己的網頁。**只有這個資料夾會被上傳到網路上** |
| `src/` | 展示中心的程式 |
| `migrations/` | 資料庫結構。**不要修改既有檔案**，一律新增 `000N_*.sql` |
| `design-system/` | 版面與配色的設計說明，你的 AI 改版面時讀得到 |
