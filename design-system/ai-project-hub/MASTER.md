# AI Project Hub 網頁設計系統

## 設計方向

- 風格：柔和、留白充足、內容優先的 Apple 類型網頁編排。
- 對象：不熟悉程式與命令列的初學者。
- 原則：清楚勝過裝飾；先顯示必要資訊，進階內容使用漸進揭露。
- 動態：只使用 150–300ms 的狀態轉場，並尊重 `prefers-reduced-motion`。

## 色彩

| 用途 | 色彩 |
| --- | --- |
| 頁面背景 | `#F6F6F4` |
| 主要卡片 | `#FFFFFF` |
| 柔和藍綠區塊 | `#EDF3F4` |
| 柔和暖色區塊 | `#F4F0E9` |
| 主要文字 | `#1D1D1F` |
| 次要文字 | `#515154` |
| 輔助文字 | `#6E6E73` |
| 主要動作 | `#35677D` |
| 主要動作 Hover | `#285367` |
| 邊框 | `#DEDEDB` |

所有一般文字與背景必須符合 WCAG AA 的 4.5:1 對比要求。資訊不可只依顏色判斷。

## 字型

使用作業系統原生無襯線字型，避免額外下載字型影響載入與中文閱讀：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
```

- 標題：650 字重、緊湊字距、大量留白。
- 內文：17px 起、行高約 1.65、每行不超過 70 個字元。
- 命令與程式碼：只在必要區塊使用系統等寬字型。

## 版面與元件

- 桌面容器上限：1120px。
- 卡片圓角：22px；大型資訊區：32px。
- 互動區最小高度：44px。
- 卡片陰影只使用輕微深度，不使用霓虹、玻璃或重色漸層。
- 手機版依 720px 與 480px 斷點改為單欄，不得出現水平捲動。
- 命令列教學預設收合，展開後每行指令都要說明用途、影響、成功畫面與停止方式。

## 禁止事項

- 不使用科技感深色背景、霓虹色、終端機視覺作為主要風格。
- 不以大量英文標籤或等寬字型製造技術感。
- 不使用 Emoji 作為結構性圖示。
- 不使用造成版面位移的 Hover 動畫。
- 不隱藏鍵盤焦點狀態。
